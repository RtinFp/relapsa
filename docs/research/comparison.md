# Comparison — TFIT · Samsung Health · Relapsa

Fill after RE. Keep one row per capability.

| Capability | TFIT | Samsung Health | Relapsa (semester) |
|------------|------|----------------|---------------------|
| Register / login | Phone + SMS OTP | Samsung account | Yes (auth) |
| Health profile (age/height/weight) | Account + physical report | Body/weight sensors | Yes |
| BMI / body metrics | BMI + BMR + body composition report | Body composition / weight | Yes (BMI; BMR later) |
| Meal / calorie log | Magazine / plans — **no free meal diary seen** | Food + NutritionPlus | Yes (core FR) |
| Activity / workout log | Daily program minutes + session plan | Workouts + sports + steps | Yes (manual) |
| Progress charts | Minutes/kcal weekly-monthly + body regions | Strong multi-metric | Yes |
| Suggestions / coaching | Trainers + subscription programs | Coach / knowledge APIs | Basic |
| Wearables / sensors | No (TWA shell) | Band/watch, HR, sleep, BT | No |
| Delivery | **TWA → web.tfit.app** | Native `com.sec.android.app.shealth` | Expo + Django |
| Local market UX (FA) | Yes (Cafe Bazaar + FA web) | No | Target |

## Scope decision

Relapsa copies **ideas and flows**, not code or assets. Semester MVP = rows marked Yes above.
