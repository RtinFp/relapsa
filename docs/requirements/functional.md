# Functional requirements

1. The system shall allow users to register and log in.
2. The system shall allow users to create and manage a health profile.
3. The system shall allow users to record daily nutrition (meals).
4. The system shall allow users to record physical activities.
5. The system shall provide progress reports and health suggestions.
