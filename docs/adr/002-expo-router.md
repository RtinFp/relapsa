# ADR-002 — Expo Router

- Status: accepted
- Date: 2026-11-03

## Context

Need clear navigation for auth, onboarding, and main tabs while learning Expo.

## Decision

Use **Expo Router** file-based routes (`app/` directory).

## Consequences

- Screen map matches `apps/mobile/README.md` (and the UC flows in `docs/02-use-cases.md`).
- Learning path is folder-by-folder, not a custom navigator soup.
